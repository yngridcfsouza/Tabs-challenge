# Formulário de Perfil em React

Este projeto é um formulário de perfil desenvolvido com **React**, utilizando **styled-components**, **validações personalizadas** com hooks e **componentes reutilizáveis**.

## ✨ Funcionalidades

- Campos controlados com `useState`
- Validação de campos obrigatórios
- Validação de e-mail com feedback ao usuário
- Mensagens de erro exibidas somente quando o campo perde o foco (`onBlur`)
- Estilização modular com `styled-components`
- Componente de formulário reutilizável com `FormGroup`

## 🛠 Tecnologias

- React
- Styled-components
- PropTypes
- Validação com hook personalizado (`useErrors`)
